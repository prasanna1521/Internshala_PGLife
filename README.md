# 🏠 PG Life – Student Accommodation Website

PG Life is a responsive Student Accommodation web application developed as part of the **Internshala Full Stack Web Development training**.

The application helps students find suitable PG (Paying Guest) accommodations based on location, budget, and gender preference. Users can create an account, log in, browse available properties, view property details, filter properties, and shortlist their preferred properties.

---

## 📌 Project Overview

Finding suitable student accommodation near colleges can be difficult. PG Life provides a simple platform where students can explore available PG properties and find accommodation according to their requirements.

The project demonstrates full-stack web development concepts using **HTML, CSS, Bootstrap, JavaScript, PHP, MySQL, and AJAX**.

---

## ✨ Features

### 👤 User Authentication
- User registration / Sign Up
- User Login
- User Logout
- Session-based authentication

### 🏠 Property Management
- View available PG properties
- Property images
- Property name and location
- Monthly rent
- Gender preference
- Property rating
- Property description
- Amenities

### 🔎 Property Filtering
Users can filter properties based on:

- City
- Gender
- Maximum budget

The filtering functionality uses **AJAX**, allowing the property list to update without refreshing the entire page.

### ❤️ Property Shortlisting
- Users can mark a property as "I'm Interested"
- Interested properties are stored in MySQL
- Users can view their shortlisted properties
- Users can remove properties from their shortlist

### 📱 Responsive Design
The application is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile devices
